  Colors: Yellow (255, 255, 0)

  Speed: 25ms per frame (smooth, fast rotation)
  Use Case: High-speed racing, maximum visibility

  Description: Color blocks rotate SEAMLESSLY and morph between purple and yellow
  Pattern: 6-LED blocks alternating between colors on 36-LED virtual ring
  Colors: Purple (128, 0, 255) ↔ Yellow (255, 255, 0)
  Brightness: 50% constant (battery efficient)
  Animation: Blocks rotate seamlessly across strip boundary while colors fade/morph
  Rotation Speed: 50ms per frame
  Fade Cycle: 1000ms (1 second for full color transition)
  Use Case: Freestyle flying, visually interesting, seamless wrap
  Special: Both strips treated as one continuous ring (no visible seam)

MODE 3: Rainbow Scroll (PWM: 1500-1749µs)
  Description: FAST scrolling rainbow with color shifting across both strips
  Pattern: Full spectrum displayed as continuous 36-LED ring
  Colors: Complete rainbow (all hues 0-255)
  Brightness: 78% (HSV value = 200)
  Animation: Rainbow scrolls FAST while colors continuously shift
  Hue Spacing: 7 per LED (creates visible rainbow spread)
  Speed: 7ms per frame (143 fps - ultra-smooth, 2x faster than v1.1!)
  Use Case: High visibility, party mode, orientation via color position, spectacular effect
  Special: Combines scrolling + color morphing for dynamic effect

MODE 4: Police Lights (PWM: 1750-2000µs)
  Description: Red/blue emergency light pattern
  Pattern: Adapted for 18 LEDs (7+4+7 sections)
  Colors: Red (178, 0, 0) / Blue (0, 0, 178) / White (178, 178, 178)
  Brightness: 100% with high/low intensity variations
  Animation: 8-stage cycle with color inversions
  Sections: 
    - First 7 LEDs: Alternating red/blue halves
    - Middle 4 LEDs: White strobe
    - Last 7 LEDs: Inverse of first section
  Strip 2: Colors inverted from Strip 1
  Speed: 22ms per stage (fast emergency effect)
  Use Case: Attention-getting, locating drone after crash
