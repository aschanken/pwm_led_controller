================================================================================

  - Yellow/purple breathing on opposite phases
  - Required: 5 bytes state (pulse offset + timer)
  - Algorithm: Sine wave calculations, dual strip control
  
NEW Mode 3: Rainbow Scroll
  - Full spectrum scrolling with color shift
  - Required: 5 bytes state (rainbow hue + timer)
  - Algorithm: HSV color generation, virtual ring mapping
  
Memory Impact:
  - State variables: Same (5 bytes)
  - Code size: +48 bytes flash (HSV conversion overhead)
  - RAM usage: -8 bytes (simpler algorithm, less stack usage)
  
Performance Impact:
  - Frame rate: 67 fps (was 50 fps) - FASTER! ✓

  - Visual complexity: Higher (full spectrum vs 2 colors)
  - CPU usage: Similar (FastLED HSV is optimized)
